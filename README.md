# Dziennik badań MMA

Strona z wynikami badań do pracy inżynierskiej
**„Ocena właściwości mieszanek mineralno-asfaltowych z zastosowaniem lepiszczy pochodzenia roślinnego”**
(Politechnika Białostocka, budownictwo drogowe). Dziennik prowadzi Claude na podstawie materiałów z laboratorium.

| Plik / folder | Zawartość |
|---|---|
| `index.html` | strona (ta sama co na claude.ai; tutaj czyta dane z plików poniżej) |
| `dane/dziennik.json` | wpisy (`entries`), receptury (`mixes`) i plan działania (`plan`) |
| `zdjecia/<id>.jpg` | zdjęcia; `id` jak w polu `photos` wpisu |
| `kalkulatory/masa.html` | kalkulator MASA (projekt mieszanki), zakładka „Kalkulator MMA” |

Przycisk w prawym górnym rogu strony: pobranie kopii (JSON, CSV do Excela) i podgląd wgranej kopii.
